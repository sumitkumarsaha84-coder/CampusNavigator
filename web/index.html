ADSA Theoretical Complexity & Viva Reference

↓

Adjacency List Graph

Space: O(|V| + |E|)

Why: Campus maps have average degree d ≈ 3-4 (|E| ≪ |V|2). An Adjacency Matrix wastes O(|V|2) space with 98%+ zeroes.

Dijkstra's Algorithm

Time: O((|V| + |E|) log |V|)

Min-Priority Queue: Binary heap extracts min in O(log |V|), far outperforming linear scanning O(|V|2) on sparse graphs.

Breadth-First Search (BFS)

Time: O(|V| + |E|)

Hop Optimality: Guaranteed to find minimum hop count (fewest intersections), but not minimum physical distance on weighted edges.

Depth-First Search (DFS)

Time: O(|V| + |E|)

Exploration: Dives deeply along the first branch using a LIFO stack. Non-optimal for distance, but vital for cycle detection and connectivity.
